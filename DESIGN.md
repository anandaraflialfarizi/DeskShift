# PadBridge native

The product is a personal screen utility, with native AppKit menus on Mac and a SwiftUI/UIKit viewer. Pairing has one code field. A successful connection shows a button for the saved Mac the next time the viewer opens. Once connected, the Mac image becomes the focal point with a small native mode picker and input controls. Discovery and network parameters stay out of the pairing form.

Use platform typography, semantic colors, dynamic type, light/dark appearance, system controls and at least 44-point input targets. The dark image canvas marks the edge of the transmitted screen, not an app-wide forced dark theme. System symbols are limited to selection/checkmark affordances. Connection and permission failures are text states; test frames are explicitly labelled. No decorative motion.
